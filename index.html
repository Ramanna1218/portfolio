01. about

Where software
meets hardware.

I'm a software engineer with a master's in computer science and 2+ years of experience developing and validating enterprise software in C#, C++, Python, and Java.

At HCLTech I worked on Teradyne's EAGLE semiconductor test platforms, building and verifying production C# .NET and C++ software that controls physical test instruments. A lot of that work was unglamorous and precise: tracking down integration defects through logs and root cause analysis, building automated test suites so releases stopped breaking, and owning system bring-up and first article validation before production release. I worked side by side with firmware and hardware engineers to fix issues that crossed layers.

I left that role to do a master's at Wright State because I wanted to work on cloud-native systems rather than around them. Alongside coursework I stayed active with the IEEE Computer Society, ACM, and Engineers Without Borders, and kept building: a full-stack Flask application deployed on AWS, containerized services with Docker and Kubernetes, and CI/CD pipelines in GitHub Actions and Azure DevOps. I'm currently working toward the AWS Certified Cloud Practitioner certification.

I'm now looking for software engineering roles where I can work on backend systems, automation, full-stack, or cloud infrastructure. If you're hiring, I'd like to hear from you.
